Password Generator
The Password Generator Application is a user-friendly GUI tool developed using Tkinter in Python. It allows users to generate passwords of varying complexity—ranging from simple lowercase letters to strong passwords with a mix of lowercase, uppercase, digits, and special characters. Users can specify the desired length of the password via a Spinbox and choose the complexity level using radio buttons. The application features a central window layout for an intuitive user experience, with clear labels, a button to trigger password generation, and an entry field to display the result. The interface is centered on the screen for convenience, and the password generation logic uses random sampling to ensure unique and secure passwords.
